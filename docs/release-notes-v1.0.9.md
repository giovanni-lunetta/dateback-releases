## 🎉 Major Rebrand: MemSavr → DateBack

We're excited to announce our complete rebrand to **DateBack**! This release includes:

### ✨ What's New

#### Branding Updates
- **New Name:** MemSavr is now DateBack
- **New Domain:** [dateback.app](https://dateback.app)
- **New Logo:** Fresh shield+clock design
- **New App Icon:** Updated macOS icon with new branding
- **Color Palette:** Refined "Stormy Morning" theme

#### Legal & Compliance
- **GPL Compliance:** Fixed legal documents to accurately reflect open source components
- **Updated Terms of Service:** Removed misleading source code references
- **Updated Privacy Policy:** Clarified data handling and GPL requirements
- **FFmpeg Source:** Public source package available at [dateback.app/licenses/ffmpeg-source.zip](https://dateback.app/licenses/ffmpeg-source.zip)

#### External Services
- **Email:** New support email at support@dateback.app
- **OAuth:** Updated Google Photos integration branding
- **Licensing:** Updated Polar.sh integration with new branding
