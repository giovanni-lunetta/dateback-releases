# Build Notes: `memory-organizer` Binary

This document captures what is known in this repository about how the `memory-organizer` binary is used and where the build command might live.

## What Is Confirmed In This Repo

- App packaging expects prebuilt macOS arm64 binaries at:
  - `assets/bin/mac-arm64/memory-organizer`
  - `assets/bin/mac-arm64/ffmpeg`
- The packaged app still receives those files at `Contents/Resources/bin/memory-organizer` and `Contents/Resources/bin/ffmpeg`.
- Electron packaging includes `assets/bin/**/*` as extra resources:
  - see `package.json` `build.extraResources`
- No `npm` script in this repo runs PyInstaller directly.
- No `.github/workflows` directory exists in this repo.

## Packaging Output (App Release Artifacts)

- App packaging in this repo is driven by `electron-builder`:
  - `npm run build`
  - `npm run build:mac`
- Release artifacts (for example macOS DMG) are generated by `electron-builder` during those build commands.
- For the complete version bump, signing, notarization, and publishing process, use the release workflow in `AGENTS.md`.

## Build Examples

- Production/default:
  - `npm run build`
- QA:
  - `npx electron-builder --config /tmp/dateback-qa-build.json --mac`

Recommended for QA builds (so QA can coexist with prod on one machine):

- Use a distinct app name and bundle ID for QA, for example:
  - `extraMetadata.productName=DateBack QA`
  - `extraMetadata.build.appId=com.giovannilunetta.dateback.qa`
- Keep signing/notarization/release automation unchanged for production unless intentionally creating a separate QA distribution flow.

## Canonical Build Command

Run from the repo root:

```bash
pip3 install -r python/requirements.txt
pyinstaller memory-organizer.spec
```

Output: `dist/memory-organizer`

After verifying the binary works, copy it to the pinned macOS arm64 binary directory:

```bash
cp dist/memory-organizer assets/bin/mac-arm64/memory-organizer
```

The root `memory-organizer.spec` is the canonical spec. The `python/memory-organizer.spec` file has been removed.
