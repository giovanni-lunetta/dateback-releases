# MemSavr v1.0.0

## 🎉 Initial Release

Archive memories the right way - 100% offline processing on your Mac.

## ✨ Core Features

### 📅 Date Preservation
- Automatically restores original dates from Snapchat exports
- Writes EXIF metadata to photos and videos
- Files display correct dates in Photos, Google Photos, and iCloud

### 💾 Smart Storage Management
- **Cloud Mode**: Process files in 500-memory batches to save disk space
- **Fast Pass**: Skip already-processed files on resume
- Real-time disk space monitoring with automatic pause/resume
- Processes 50GB+ exports without filling your hard drive

### 🎨 Modern Glassmorphism UI
- Beautiful frosted glass effects and dark mode design
- Drag & drop ZIP file interface
- Real-time progress tracking with accurate ETA
- Storage dashboard with live space monitoring

### 🔄 Advanced Processing
- Merges main images/videos with Snapchat overlays
- Multi-threaded processing (10-20 workers)
- Handles corrupted files gracefully with error reports
- Retry functionality for failed downloads

### 🛡️ System Safety
- Battery awareness with power warnings
- Prevents Mac sleep during processing (caffeinate mode)
- Disk full protection with early warnings
- Secure sandbox environment

### 🔑 Licensing & Updates
- Lemon Squeezy integration for secure licensing
- Automatic updates via GitHub releases
- Notarized and code-signed for macOS security

## 📥 Installation

Download the DMG file below and drag MemSavr to your Applications folder.

**Platform**: macOS (Apple Silicon arm64)  
**Minimum**: macOS 11.0 Big Sur or later

## 🚀 Getting Started

1. Request your Snapchat data at [accounts.snapchat.com/accounts/downloadmydata](https://accounts.snapchat.com/accounts/downloadmydata)
2. Wait for Snapchat to email you the download link (can take 1-2 weeks)
3. Download `mydata.zip`
4. Open MemSavr and drag the ZIP file into the app
5. Click "Start Processing" and let MemSavr do the rest!

**Note**: Future updates will be delivered automatically via the built-in auto-updater! 🎉
