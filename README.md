# MemSavr Releases

This repository contains official releases for MemSavr - The Professional One-Click Archiver for Snapchat Memories.

**Download the latest version:** [Releases](https://github.com/giovanni-lunetta/memsavr-releases/releases)

MemSavr is a macOS application that processes Snapchat memory exports, restores original dates, and organizes files for cloud upload.
